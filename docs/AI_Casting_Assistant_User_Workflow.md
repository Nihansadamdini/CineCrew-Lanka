# AI Casting Assistant – User Workflow

### 1. Open AI Casting Assistant
The Director/Producer opens the AI Casting Assistant from the dashboard.

### 2. Select a Production
The user selects the film or teledrama production for which they need to find suitable actors.

### 3. Enter Character Requirements
The user enters the requirements for the character:

- Character description
- Age range
- Required skills
- Languages
- Other requirements

### 4. Click "Find Suitable Actors"
The user submits the character requirements by clicking the **Find Suitable Actors** button.

### 5. AI Processes the Request
The AI system processes the request through three main stages:

- **Retrieval:** Retrieves relevant talent profiles from ChromaDB.
- **Filtering:** Filters candidates according to the character requirements.
- **Ranking:** Ranks suitable candidates using the LLM.

### 6. View Ranked Actor Recommendations
The user views a list of recommended actors, ranked according to their suitability, with match scores and explanations.

### 7. Review Profiles and Add Actors to Shortlist
The user reviews the recommended actors' profiles and adds suitable candidates to the production's shortlist.
